# Serenes Forest Companion

[English version](README.md)

Нативный справочник по Fire Emblem для iOS 26+ и macOS 26+, написанный на SwiftUI. Приложение поставляется с заполненной базой SwiftData: статьи, каталоги игр и ссылки на медиа доступны сразу после установки. При первом запуске база копируется в доступное для записи хранилище приложения. Для чтения статей не нужно скачивать исходные JSON-файлы или ждать загрузки текста из сети.

Статьи отображаются нативными компонентами: текст, списки, изображения и таблицы с горизонтальной прокруткой. Изображения загружаются при первом просмотре и сохраняются в локальном кэше. У каждой статьи есть ссылка на источник; новые и изменённые страницы приложение находит по датам в sitemap.

## Сборка и запуск

1. Установите Git LFS и выполните в каталоге проекта `git lfs install && git lfs pull`. Предустановленная база хранится в LFS и занимает около 196 МиБ.
2. Откройте `SerenesForest.xcodeproj` в Xcode 26 или новее.
3. Выберите схему **SerenesForest** и симулятор с iOS 26+ либо **My Mac** с macOS 26+.
4. Соберите и запустите приложение. Первоначальная загрузка статей из сети не требуется.

Для запуска на физическом устройстве укажите собственный Apple Developer Team и идентификатор приложения. Локальные настройки подписи храните в `Config/Signing.local.xcconfig`; этот файл исключён из Git. Учётная запись для использования приложения не нужна. Дополнительные шаги и карту каталогов см. в [краткой инструкции](docs/QUICKSTART.md).

## Архитектура

Проект организован по функциональным экранам и локальным Swift-пакетам. Приложение собирается в режиме языка Swift 6; для пакетов указан `swift-tools-version: 6.1`:

| Каталог | Назначение |
| --- | --- |
| `Sources/LocalPackages/SerenesParsing` | Канонизация URL, разбор HTML, RSS и sitemap без зависимостей от SwiftUI и SwiftData. |
| `Sources/LocalPackages/SerenesNavigation` | Типизированные маршруты статей и наблюдаемое состояние навигации. В маршрутах хранятся URL, а не объекты SwiftData. |
| `Sources/Domain` | Модели библиотеки SwiftData и нативное представление статей. |
| `Sources/Parsing` | Разбор дерева и блоков статьи. |
| `Sources/Mapping` | Преобразование разобранного контента в записи библиотеки, категории, описания игр и данные перевода. |
| `Sources/Data` | Импорт предустановленного контента, синхронизация и загрузка изображений. |
| `Sources/Screens/<Feature>` | Экраны SwiftUI и отдельные `@Observable` ViewModel. |
| `Sources/Shared` | Общие компоненты интерфейса и стили. |
| `Sources/App` | Точка входа и настройка контейнера моделей. |

View отображают состояние и выполняют навигацию. ViewModel отвечают за состояние экрана, фильтрацию, сортировку, пагинацию, перевод и подготовку данных. Сервис синхронизации передаётся через окружение SwiftUI. Статические строки интерфейса вынесены в локальные `Constants` файлов. Для View принято ограничение в 300 строк, для ViewModel — в 500 строк.

Проверка отдельного модуля парсинга: `swift test --package-path Sources/LocalPackages/SerenesParsing`.

## Предустановленная библиотека и изображения

`Resources/PreloadedLibrary` содержит готовую базу SwiftData: 5 067 страниц, 25 177 ссылок на медиа, 22 игры и 1 693 связи между статьями вики и играми. Большие исходные JSON/JSONL-файлы в репозитории и сборке приложения не хранятся. Небольшие обложки игр входят в приложение, остальные изображения загружаются по сохранённым ссылкам и кэшируются при просмотре.

Команда **Настройки → Хранилище → Очистить загруженные изображения** удаляет локальный кэш изображений, сохраняя статьи, ссылки, другие загруженные файлы и встроенные обложки. При следующем просмотре изображение можно загрузить снова.

Файлы Python в `scripts/` нужны только для пересоздания базы и ассетов. Xcode не запускает их и не включает в бинарь. Чтобы обновить предустановленную базу, создайте пять исходных файлов в игнорируемом каталоге `BuildContent/` с помощью скриптов ниже, затем на macOS запустите `python3 scripts/build_preloaded_library.py`. Исходные файлы можно хранить вне проекта и передать их каталог через `SERENES_SOURCE_CONTENT_DIR`. Скрипт исключает байты изображений из временных JSONL, собирает приложение, импортирует текст и метаданные в новую базу, проверяет целостность и число записей и заменяет `Resources/PreloadedLibrary`. После этого пересоберите приложение. Для расширения текущего снимка недостающими статьями, медиа и материалами вики выполните `python3 scripts/expand_preloaded_content.py --output /private/tmp/serenes-expanded-content`, затем соберите базу с `SERENES_SOURCE_CONTENT_DIR=/private/tmp/serenes-expanded-content`. У уже установленных копий сохраняются собственная база, закладки, переводы и загруженные обновления; новые установки получают обновлённую предустановленную базу.

Иконка приложения и изображение в шапке главного экрана используют [Shield of Flames из Fire Emblem Wiki](https://fireemblemwiki.org/wiki/File:FEWA_Shield_of_Flames_complete.png). Страница файла указывает правообладателя и условия использования. Для повторной генерации размеров иконки выполните `swift -module-cache-path /private/tmp/serenes-swift-module-cache scripts/build_app_icon.swift` из корня проекта.

## Контент и обновления

- База создана из страниц Serenes Forest; при недоступности сайта использовались публичные копии Wayback. Руководство каждой игры сохраняет разделы и порядок ссылок главной страницы игры. При обновлении этой страницы её меню меняется вместе с ней. Новые статьи обнаруживаются через sitemap.
- Каталог из 22 игр поддерживает поиск, сортировку по названию, дате выпуска и статусу, а также фильтрацию. Раздел «Игры серии» сначала показывает прежний набор из восьми игр; недавно открытые игры постепенно заменяют его карточки. Большие списки статей в **All pages**, **Fire Emblem Wiki** и **Guides** выводятся порциями.
- Английский и русский языки выбираются в настройках. На поддерживаемом устройстве фреймворк Apple Translation переводит навигацию и содержимое открытых статей. Переводы сохраняются и повторно используются, пока исходная страница не изменится. Системе может потребоваться загрузить языковой пакет; в симуляторе перевод не запускается, но сохранённый перевод отображается.
- Раздел Fire Emblem Wiki включает 1 443 нативные статьи о персонажах, главах, классах, механиках и мирах игр. Общие статьи связаны с несколькими играми. Таблицы и вкладки сложности хранятся в предустановленной базе; изображения вики загружаются и кэшируются по мере просмотра. У статей есть ссылки на источник и историю правок. Текст вики распространяется на условиях GNU Free Documentation License 1.3; её текст включён в `Resources/GFDL-1.3.txt`.
- Закладки привязаны к локальным записям статей и переживают их обновление. Раздел **Saved pages** позволяет найти и открыть сохранённые страницы внутри приложения. Галереи Official Artwork и связанные статьи также открываются в нативном интерфейсе.
- При запуске приложение проверяет sitemap не чаще раза в 24 часа. Загружаются только новые или изменённые страницы; автоматическая проверка обрабатывает не более 24 изменений за раз. **Check updates** запускает обработку всех ожидающих изменений. Ошибка сети не удаляет имеющийся контент.
- Раздел **News** проверяет новые публикации не чаще раза в 15 минут; жест обновления запускает проверку сразу. Встроенные новостные ленты игр содержат первые две страницы RSS, а более старые записи можно запросить отдельно.
- Файлы медиа и изображения загружаются по требованию. При недоступности сайта запрос может использовать сохранённую копию Wayback. Для каждого сетевого запроса задан тайм-аут; HTTP ETag и Last-Modified позволяют избежать повторной загрузки неизменённых страниц.
- Статьи представлены текстом SwiftUI, списками, изображениями и таблицами без WebView. Длинные таблицы прокручиваются в ограниченной области с закреплёнными заголовком и первым столбцом. Внутренние ссылки ведут к нативным статьям, внешние требуют подтверждения. PDF, изображения, аудио и видео можно просмотреть или отправить через раздел медиа.

Для повторной сборки исходного контента используйте `scripts/build_seed.py`, `scripts/repair_seed.py` и `scripts/build_spin_off_seed.py`. Файлы вики создаются последовательно командами `python3 scripts/build_wiki_library.py`, `python3 scripts/build_wiki_images.py`, `python3 scripts/build_wiki_full_content.py`, `python3 scripts/expand_wiki_chapters.py` и `python3 scripts/build_wiki_inline_images.py`. Входной файл новостей обновляет `python3 scripts/build_game_news.py`. Индекс медиа создаёт `python3 scripts/build_seed_assets.py`; опция `--page-list` ограничивает обработку выбранными статьями. Обложки и миниатюры разделов генерируют `scripts/build_game_covers.py` и `scripts/build_section_art.py`. Загрузка всех изображений в исходные файлы может потребовать много места, хотя сами байты изображений не входят в предустановленную базу.

Serenes Forest, Fire Emblem Wiki, тексты и изображения принадлежат их авторам и правообладателям. Приложение указывает источники статей. Перед распространением приложения с копиями страниц проверьте условия использования контента у владельцев сайтов. Это неофициальное приложение и не выдаёт новую лицензию на материалы третьих лиц.
